关于 英入眼帘

把生词编织成文章，让学习自然发生

🎯 产品定位

输入 5 个以上新学的英文单词，系统会根据词汇语义生成两篇覆盖全部目标词汇的英文短文， 并完成中文翻译、英文朗读、阅读理解出题。让每个生词在真实语境中被理解、被记住。

⚙️ 工作流程

1词汇分析清洗、去重、格式校验
2文章生成根据语义生成两篇短文
3覆盖检测词汇覆盖率检测与重试
4中文翻译自然流畅的中文翻译
5阅读理解雅思风格选择题出题
6语音朗读英文朗读与语速调节
7记录保存学习记录持久化存储

📖 使用流程

  1. 在首页输入 5 个以上新学的英文单词，确认拼写后点击「开始生成」
  2. 系统根据词汇语义生成两篇短文，并自动检测词汇覆盖
  3. 查看两篇英文文章、中文翻译与目标词汇高亮
  4. 点击播放按钮收听英文朗读，可调节语速
  5. 完成 6 道阅读理解选择题（每篇文章 3 题），提交后查看答案与解析
  6. 可重新生成或导出学习报告，所有记录自动保存到历史记录

🛠 技术栈

Python + Flask · 智谱 AI（GLM + CogView）· Edge TTS · SQLite · HTML/CSS/JS
